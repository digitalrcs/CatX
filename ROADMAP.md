# Roadmap

CatX 1.0 provides the core keyboard guard and built-in desktop cats. Potential future work is listed here without a delivery commitment.

## Near term

- Add automated tests around settings parsing and recovery-chord matching.
- Add a signed installer and Authenticode-signed release executable.
- Package a native Windows ARM64 build.
- Add an application icon and release screenshots.

## Later exploration

- Optional system-tray controls and a clearly visible guarded-state indicator.
- More original built-in cat animations and movement behaviors.
- Accessible high-contrast controls and additional localization.
- Carefully sandboxed custom cat packs with a documented asset-only format.

## Non-goals

- Capturing, logging, analyzing, or transmitting typed keys.
- Circumventing the Windows secure-attention sequence.
- Running a hidden persistent lock, driver, or Windows service.
- Automatically enabling the guard at startup without an explicit, reversible user choice.

Suggestions are welcome through GitHub Discussions or feature requests once those facilities are enabled.
