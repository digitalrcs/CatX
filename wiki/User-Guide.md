# User guide

## Configure CatX

Choose one of the five original vector cats - Marmalade, Midnight, Snowball, Tuxedo, or Calico - or select **No cat** for keyboard protection without a desktop animation.

Choose and remember a recovery shortcut:

- `Ctrl + Alt + K`
- `Ctrl + Shift + F12`
- `Alt + Shift + Pause`

You can also select how often the cat moves and an optional auto-lock inactivity period. Keyboard or mouse activity resets the inactivity timer; CatX enables the guard only after the full selected period with no input.

## Enable and disable the guard

1. Choose your settings.
2. Select **Enable keyboard guard**.
3. Test the displayed recovery shortcut immediately.
4. Use the shortcut or **Disable guard with mouse** to restore typing.

## System tray

Minimizing CatX hides its taskbar button and places a cat icon in the Windows notification area. Right-click the icon to:

- **Open CatX**
- **Disable keyboard guard** when the guard is active
- **Exit CatX**

Double-click the icon to reopen CatX.
