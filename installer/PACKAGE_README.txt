CatX Keyboard Guard 1.1.1 for Windows 11
Dan Roberts - DigitalRCS

INSTALL

1. Extract every file from this ZIP to a folder.
2. Double-click Setup.exe.
3. Follow the installation prompts.
4. Optionally create a desktop shortcut.
5. Launch CatX Keyboard Guard.

Before enabling the keyboard guard, select and test a recovery shortcut.
The mouse remains available while the guard is active.

The installer is currently unsigned. Windows SmartScreen may display a warning.
Confirm that this ZIP came from the official DigitalRCS CatX release before
choosing More info and Run anyway.

The included CatX-User-Guide.pdf contains setup, safety, recovery,
troubleshooting, privacy, and uninstall instructions.
USER_GUIDE.md and ANIMATED_CATS.md describe the new realistic cats,
keyboard-safe preview, cursor chasing, and toy mouse play in 1.1.0.
The PDF is the existing 1.0.3 keyboard-guard reference.

SYSTEM REQUIREMENTS

- 64-bit Windows 11
- No separate .NET installation required
- No administrator privileges required
- No account or Internet connection required to run CatX

UNINSTALL

Open Windows Settings, select Apps, select Installed apps, find
CatX Keyboard Guard, and choose Uninstall.
