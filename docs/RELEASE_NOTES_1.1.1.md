# CatX 1.1.1

The reviewed animation and multiple-cat update is here.

- Choose **1–8 cats**, each with its own original or realistic style.
- Realistic cats now draw one complete pose at a time, eliminating overlapping frames that looked like extra legs.
- Regular corner naps keep the head still while only the tail tip twitches.
- Realistic grooming uses the model's original paw-washing motion. The rejected custom ear reach is removed; original animated cats keep their approved ear-grooming motion.
- The toy mouse moves slowly, ventures farther out, and returns through its cartoon mouse hole. Holes appear at random desktop locations.
- **Preview action** lets you immediately inspect Sleep, Groom, Walk, Run, or Mouse visit without enabling the keyboard guard. Preview mode supports all selected cats.

## Download and install

Download **CatX-Windows11-1.1.1.zip**, extract all files, and run **Setup.exe**. The standalone **CatX-Setup-1.1.1.exe** installs the same application.

For a portable copy, download **CatX-win-x64.zip** and run **CatX.exe**. Its optional **Start-Animation-Review.cmd** launcher starts a safe review session with the keyboard guard disabled and saved preferences unchanged.

Blender and a separate .NET installation are not required. The current Markdown user guide and animation documentation are included, alongside the existing 1.0.3 PDF reference. Use **USER_GUIDE.md** for the latest features. **SHA256SUMS.txt** contains download checksums.

This release remains **unsigned**; Windows may display an unknown-publisher or SmartScreen warning. Realistic-cat assets are derived from an owner-supplied third-party model and are not covered by the CatX source-code MIT license; see ANIMATED_CATS.md for provenance.
