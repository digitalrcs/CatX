# CatX 1.1.0

Seven realistic cats join the original five companions: Tabby, Orange, White, Grey, Tuxedo, Black, and Bicolor. Their transparent animations are rendered from the supplied Blender model and run without Blender on the user's PC.

All cats walk with smooth acceleration, sit, groom, lie down, sleep in lower corners, and wake. Rapid cursor direction changes trigger a playful chase. An occasional toy mouse attracts attention and escapes before contact. Both play behaviors can be toggled independently. Preview cat leaves the keyboard active and pauses automatic locking until preview is stopped.

Download **CatX-Windows11-1.1.0.zip**, extract it, and run **Setup.exe** to install. For a portable copy, download **CatX-win-x64.zip** and run **CatX.exe**. Blender and a separate .NET installation are not required.

The packages include all animation frames, the current Markdown guide, an animation addendum, and the existing 1.0.3 PDF reference. Read USER_GUIDE.md and ANIMATED_CATS.md for the new features. SHA256SUMS.txt contains download checksums.

This release is unsigned; Windows may display an unknown-publisher or SmartScreen warning. The realistic-cat assets are derived from an owner-supplied third-party model and are not covered by the CatX source-code MIT license. See docs/ANIMATED_CATS.md for provenance details.
