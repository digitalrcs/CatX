# CatX 1.0.3

CatX 1.0.3 corrects the coat markings on the Calico, Tuxedo, and Midnight desktop cats.

## Fixed

- Midnight now has a clean solid coat without misplaced contrasting spots.
- Tuxedo keeps its black coat and white chest without a stray face or flank patch.
- Calico's dark crown marking stays above the eyes, and its orange marking remains on the flank.
- Coat-pattern regression tests protect these style-specific choices.

## Downloads

- `CatX-Windows11-1.0.3.zip` - recommended package. Extract it and run `Setup.exe`.
- `CatX-Setup-1.0.3.exe` - standalone Windows installer.
- `CatX-win-x64.zip` - portable self-contained executable.
- `CatX-User-Guide-v1.0.3.pdf` - printable user documentation.
- `SHA256SUMS.txt` - SHA-256 checksums for verifying downloads.

## Requirements

- 64-bit Windows 11.
- No separate .NET installation is required.
- No administrator privileges, account, or Internet connection are required to run CatX.

## Important safety information

Select and test a recovery shortcut immediately after enabling the guard. The mouse remains available, the tray menu can disable the guard, closing CatX removes its keyboard hook, and Windows `Ctrl + Alt + Delete` remains available.

CatX 1.0.3 is currently unsigned. Windows SmartScreen may display a warning. Download CatX only from the official DigitalRCS GitHub release and verify the SHA-256 checksum before running it.
