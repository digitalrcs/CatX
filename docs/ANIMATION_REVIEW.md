# CatX animation preview

CatX 1.1.1 includes the reviewed sleep/groom animations, longer mouse excursions from random desktop locations, and multiple independently styled cats.

1. Run **Start-Animation-Review.cmd** from the extracted portable ZIP, or launch `CatX.exe --review` from the application's folder. No Blender is required. This review session disables the guard and automatic locking, and leaves existing saved preferences unchanged. Normal CatX also offers keyboard-safe preview through its Preview cats button.
2. Choose your first cat, then select **Cats on screen** (1–8). Choose a style for each additional cat. Original and realistic cats can be mixed. **No cat** hides all companions.
3. Click **Preview cats**. Your keyboard stays active and automatic locking pauses until you stop preview.
4. Choose **Sleep**, **Groom**, **Walk**, or **Run** under **Preview action** to inspect that animation in place on every selected cat. Choose **Mouse visit** for a prompt toy visit, or **Natural** for normal independent behavior. Leave Toy mouse visits enabled to see the mouse.
5. Click **Stop preview** to close every cat and mouse. In normal CatX this resumes any configured inactivity timer from zero; the dedicated `--review` session keeps automatic locking disabled.

## Things to review

- Sleep: the realistic cat keeps its head and body settled; only the very last tail segment twitches intermittently. Original cats also have a separate animated tail tip.
- Groom: realistic cats use the supplied model's simpler paw-washing motion. The custom ear reach and its shoulder/leg bending have been removed. Original animated cats retain their approved paw/tongue/ear-wiping poses unchanged.
- Mouse: holes can appear throughout the monitor's working area; the mouse travels farther (typically 340–640 logical pixels on roomy displays) at the same slow 80 logical pixels per second, pauses, and returns through the same hole. Small displays or nearby cats can limit a visit's distance.
- Multiple cats: different styles should appear together, start apart, and stop together. Each has independent activity timing. More realistic cats use more memory and rendering resources; reduce the count on smaller PCs.

The application is the best place to check actual on-screen size and performance. The release remains unsigned. Earlier local review bundles also contain looping GIF previews; those GIFs are not required by the application.
