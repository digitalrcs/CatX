# Support

CatX is a community project.

- Read the [troubleshooting guide](docs/TROUBLESHOOTING.md) for recovery and common problems.
- Use GitHub Issues for reproducible bugs and feature requests.
- Use GitHub Discussions for usage questions when Discussions is available.
- Report security-sensitive recovery failures privately as described in [SECURITY.md](SECURITY.md).

When requesting help, include the CatX version, Windows version, CPU architecture, keyboard layout, chosen recovery shortcut, and steps to reproduce. Never share passwords, authentication codes, private typed content, or security tokens.
